## Flagship Product: Axiom Trading Journal

A trading journal built for Forex traders to log trades, review performance and improve discipline.

- Log trades with automatic pips, risk-to-reward and P&L calculation
- Dashboard and analytics for tracking performance
- Custom risk rules per trading account
- Trading psychology insights based on mood tags
- Dark mode and multiple trading accounts

🔗 **Try it:** [myaxiomjournal.com](https://myaxiomjournal.com/)
